# Daber Hebrew Coach

Independent reconstruction of the visible Daber Hebrew Coach experience. Provides eight beginner lessons, Hebrew word breakdowns, browser speech pronunciation, translation and reading practice, conversation/foundations/review modes, progress indicators, and local-only progress storage.

No original source was available in the matching `AWEMISSIONS/Daber-Hebrew-Coach` repository or from Sites source preparation. This rebuild follows the live app’s visible interaction pattern and is not a source recovery. Learning content is original sample beginner material; later course tiers from the original are not reproduced.

Open `index.html` directly or deploy as a static site. Requires no backend. Speech playback depends on a Hebrew voice installed on the device.
